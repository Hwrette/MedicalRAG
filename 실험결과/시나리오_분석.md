# 시간 단위를 보정한 뒤 다시 실행한 5개 시나리오

## 실험 방법

제공된 7일치 입력을 사용해 각 날짜까지만 temporal.py의 수치 입력 모드에 전달했다. 5개 사례 × 3개 센서 × 7개 종료 시점으로 총 105회를 실행했다. 각 CLI 출력과 프로그램의 derive 결과를 비교하고, 입력 소수를 분수로 바꿔 별도로 구한 R 및 D와 대조했다. R은 2일차부터 90개, D는 3일차부터 75개가 계산됐다. 등급 경계의 반올림 오차도 수정해 정확히 20점인 5건이 모두 band_1로 분류됐다.

## 7일차 결과

각 칸은 R / D 순서다. D 단위는 pH/일 또는 ℃/일이다. CO₂ 열의 입력값은 페놀레드 패치의 pH다. 원래 시나리오 이름은 가상 상황의 이름이며 실제 감염 여부를 나타내지 않는다.

| 사례 | BTB pH | 페놀레드 pH | 온도 | 관찰한 변화 |
|---|---:|---:|---:|---|
| 1. 지속 변화 | 92 / −0.05 | 92 / +0.05 | 32 / −0.05 | 두 pH가 서로 반대 방향으로 진행하며 각각의 한계에 접근해 두 R 모두 92에 도달했다. |
| 2. 일부 지표 변화 | 34.67 / +0.05 | 20 / −0.10 | 48 / +0.55 | 온도는 끝에 하루 0.7℃ 올라 세 점수 중 가장 높았다. |
| 3. 작은 변동 | 16 / −0.10 | 20 / −0.05 | 6 / 0 | 입력 범위가 좁아도 작은 등락이 변화율 항에 반영됐다. |
| 4. 6일차 급변 | 62.67 / −1.05 | 62.67 / +1.05 | 15.05 / −0.95 | 6일차의 R은 각각 152, 152, 80이었다. 7일차에는 변화 방향이 반전돼 R이 낮아졌다. |
| 5. 상승 후 복귀 | 4 / +0.05 | 4 / −0.05 | −2 / +0.05 | 온도의 마지막 변화율은 −0.3℃/일이다. 기본 항 10점에 변화율 항 −12점이 더해졌다. |

## 단위와 판정의 해석

두 HTML 기본값은 현재점을 제외한 이전 최대 3점으로 회귀한다. D는 최근 변화율에서 이 회귀 기울기를 뺀 값이다. 같은 관측 시각을 분에서 일로 표시하면 D와 경계 모두 1,440배가 된다. BTB pH 경계는 0.02와 0.1에서 28.8과 144로, 온도 경계는 0.2와 1에서 288과 1,440으로 환산했다. 페놀레드의 자체 기준 자료가 없어 BTB와 같은 pH 경계를 가정했다.

HTML은 R 가중치를 제공하지 않는다. 이번 일 단위 연구 점수는 경고 방향으로 하루 0.5단위 변할 때 변화율 항이 한 등급 폭인 20점만큼 기여하도록 β=40을 사용했다. BTB와 온도는 상승, 페놀레드는 하락이 가점 방향이다. 기존 BTB·페놀레드의 β=500을 40으로 조정했고 온도는 기존 β=40을 유지했다. 이는 실험용 척도 선택이다. 동일한 R을 분당 기울기로 구현하면 β(분)=1,440×β(일)이다.

D가 계산된 75건 모두 similar_to_trend였다. 4번 6일차에는 BTB D=+1.7, 페놀레드 D=−1.7, 온도 D=+1.4로 세 지표의 급변이 원수치에 나타났다. 일 단위로 환산한 첫 경계는 각각 28.8과 288이므로 등급은 그대로였다. 같은 순간들의 시간 표기를 바꾸는 것과 측정 간격 자체를 하루로 늘리는 것은 다르다. 분 단위 실험의 경계를 보존하면 이 데이터에서는 일별 급변을 구분할 수 없다. 일별 경계를 정하려면 반복 측정 오차와 별도의 일별 변화 자료를 확보해 설정하고, 독립 사례로 재검증해야 한다.
