# 세 패치의 7일 시계열 실험

5개 사례의 BTB 패치 pH, 페놀레드 패치 pH(CO₂ 간접 지표), 온도패치(℃)를 각각 실제 temporal.py의 입력으로 실행했다. 동일한 7일 자료에서 1일까지만, 2일까지, …, 7일까지의 결과를 구해 미래 값이 앞선 날의 판단에 들어가지 않게 했다. 5사례 × 3패치 × 7시점 = 105개 조건이 모두 정상 종료했다.

## 측정값과 계산 방향

s는 가장 최근 두 점의 변화율, b는 현재 점을 포함한 최근 최대 7점의 최소제곱 회귀 기울기다. 세 패치 모두 D=s−b이며 시간 단위는 일이다. 1일 차는 이력 부족, 2일 차는 R과 s만, 3~7일 차는 D까지 계산한다.

| 패치 | 계산 가능 구간에서의 연구용 점수 R | D의 작은 경계 / 큰 경계 |
|---|---|---|
| BTB pH X | 40/(8.5−X)+500s | 0.018 / 0.030 pH/일 |
| 페놀레드 pH C | 40/(C−5.5)−500s | 0.018 / 0.030 pH/일 |
| 온도 T | 40/(40−T)+40s | 0.015 / 0.040 ℃/일 |

**이번 실험에서 새로 둔 가정.** 페놀레드용 R 계수와 하한은 기존 자료에 없었다. 두 패치 모두 pH 척도를 사용하므로 비교용으로 BTB 식을 pH 7에 대해 대칭시켰다. 즉 BTB 식에 14−C를 넣은 결과와 같다. 이 선택으로 C가 낮아지거나 빠르게 내려가면 R이 커진다. 5.5는 수식의 계산 하한이며 감염 판정 기준이 아니다. 하한 이하에서는 R을 비워 두고 limit_exceeded로 표시한다. D는 원래 pH 축에서 계산하므로 음의 D는 최근 페놀레드 pH 기울기가 회귀 기울기보다 낮다는 뜻이다. 이 계수·경계는 실측으로 교정되지 않았다.

## 7일 차 결과와 전환점

각 칸은 R / D이다. 서로 다른 패치 점수를 더하거나 평균 내지 않았다.

| 입력 시나리오 | BTB pH | 페놀레드 pH | 온도 |
|---|---:|---:|---:|
| 1 서서히 확실한 감염 | 230.00 / −0.0357 | 230.00 / +0.0321 | 32.00 / −0.0357 |
| 2 서서히 애매한 감염 | 126.67 / +0.0357 | 66.00 / −0.1000 | 48.00 / +0.3929 |
| 3 정상 | 16.00 / 0.0000 | 66.00 / −0.1071 | 6.00 / −0.0893 |
| 4 정상 → 급격한 감염 | 16.67 / −0.4607 | 16.67 / +0.4607 | 15.05 / −0.4393 |
| 5 정상 → 서서히 약한 감염 → 정상 | −134.00 / −0.2964 | −134.00 / +0.2929 | −2.00 / −0.3000 |

1. **지속 변화.** 1행 마지막 날 BTB는 7.7→8.0, 페놀레드는 6.3→6.0으로 움직였다. 두 R이 같은 230인 것은 대칭 수식과 마지막 두 점이 대칭이기 때문이다. 독립적으로 같은 감염 확률을 관측했다는 의미는 없다.
2. **서로 다른 변화.** 2행 온도는 마지막 날 37.3→38℃로 뛰어 D가 +0.3929였다. 같은 날 페놀레드 pH는 8.1→8.0으로 조금 내려가도 R이 66이었다.
3. **작은 변동.** ‘정상’으로 설계한 3행도 마지막 날 페놀레드 pH가 0.1 내려가면서 R에 50점이 더해졌다. BTB도 5·6일 각각 65.38, 66.00이다. 현재 계수는 이런 작은 움직임에도 민감하다.
4. **급변.** 4행 6일 차 BTB 6.2→8.0, 페놀레드 7.8→6.0, 온도 36.5→38℃에서 R은 각각 980, 980, 80이다. D는 각각 +1.4857, −1.4857, +1.1886이다. 7일에 변화 방향이 뒤집히자 여전히 5일과 다른 측정 수준에서도 세 R 모두 20 아래로 떨어졌다.
5. **되돌아오는 변화.** 5행의 세 측정값은 마지막 날 첫날 값으로 돌아왔다. R은 현재값뿐 아니라 직전 변화율도 사용하므로 세 점수 모두 음수가 됐다. 음수는 수식 결과로 band_0에 들어간다.

## 검증과 해석 범위

105개 CLI 출력과 입력 이력을 받는 derive() 경로를 대조했다. 계산 가능한 R 90개와 D 75개는 십진 입력을 분수로 변환해 독립 계산한 값과 절대 오차 10⁻⁹ 이내에서 일치했다. R 등급과 D 상태도 정확한 분수 기준과 모두 일치했다. 직전 실험에서 확인된 D 경계의 실수 오차는 경계로부터 10⁻¹² 이내일 때 해당 경계로 분류하도록 수정했다. 원래 계산한 D 수치는 그대로 출력한다.

사례 이름은 사용자가 설계한 변화 패턴이다. 감염 진단이나 임상적 정확성을 검증한 실험은 아니다. 점수는 특히 한계값 부근과 하루 변화량에 민감하다. 이번 범위는 세 패치의 temporal 계산이며 전문가 시스템의 Q01·Q02 적용 범위는 기존 BTB pH와 온도다.
